# Projekt zespołowy

Repozytorium do ćwiczenia współpracy z GitHubem.

## Autorzy
- Właściciel repozytorium: @MichalRobok
- Współpracownik: @jkuzniar4i

## Cel
Ćwiczenie pracy z Issues, gałęziami, Pull Requestami oraz ochroną gałęzi `main`.

## Zasady współpracy
1. Zadania i błędy zgłaszamy w Issues.
2. Zmiany wprowadzamy na osobnych gałęziach.
3. Gotowe zmiany proponujemy przez Pull Request.
4. Gałąź `main` chronimy przed bezpośrednimi zmianami.
